# Forma — motion editor

Статический редактор анимационных сцен на HTML, CSS и JavaScript. Работает на
GitHub Pages, без сборки, сервера приложения, платных API и внешних шрифтов.

## Запуск

```sh
npm start
```

Рабочая директория: `/workspace/for_test`. Нужен Python 3; HTTP-сервер слушает
порт 3000. Используйте существующий checkout; отдельный Git worktree не нужен.
В новой облачной машине сервер необходимо запустить повторно.

## Возможности

- Шесть 3D-пресетов: каскад, орбита, editorial, устройства, волна, галерея.
  Реальные CSS 3D-слои, общая камера, перспектива, толщина карточек, динамические
  тени и блики, согласованное появление с задержкой между кадрами.
- Пресеты добавляются на таймлайн нажатием или перетаскиванием. Клипы можно
  дублировать, удалять, переставлять мышью и кнопками. Правая граница клипа
  меняет длительность. Между сценами — перекрытие до 0,45 с.
- Каждый клип хранит свои кадры, фон, скорость, easing, настройки камеры,
  глубины, расстояния, движения, света и теней. Длительность при скорости 1×
  делится на скорость, чтобы получить фактическую длину клипа на таймлайне.
- До 8 кадров на пресет: дизайн, текст, изображения и видео. Есть множественная
  загрузка, замена файла, перестановка, дублирование и удаление кадров.
  Выбранный кадр имеет собственные текст, размер шрифта, цвет, X/Y/Z, поворот,
  масштаб, непрозрачность и задержку. Кадры автоматически вписываются в раскладку.
- Произвольный размер композиции и форматы 16:9, 1:1, 4:5, 9:16.
- Воспроизведение, пауза, перемотка, переходы между клипами, зацикливание,
  масштабирование таймлайна и прокрутка вслед за курсором.
- Сохранение и открытие JSON-проектов версии 2 со встроенными используемыми
  медиафайлами. Ничего не отправляется на сервер. Файлы из библиотеки, которые
  не используются в кадрах, не включаются в сохранённый проект.

Горячие клавиши: пробел — воспроизведение/пауза, стрелки — ±1/30 с,
Shift + стрелки — ±1 с, Delete/Backspace — удалить выбранный клип,
Ctrl/Cmd + S — сохранить проект. Горячие клавиши монтажа не перехватывают ввод
в текстовых полях, числах и других элементах редактирования.

## Проверки

```sh
npm run check
npm test
```

Семь тестов движка проверяют время и перекрытие клипов, скорость, детерминированную
перемотку, все пресеты с восемью слоями, индивидуальные трансформации, easing,
переносимость проекта и отклонение повреждённых данных.

Браузерные тесты требуют Playwright, Chromium и запущенного сайта. Установите
Playwright в своё окружение. Можно задать `PLAYWRIGHT_MODULE` (путь к пакету),
`CHROMIUM_PATH` (путь к установленному браузеру) и `FORMA_TEST_URL` (адрес сервера).

```sh
npm run test:browser
```

Проверяются пробел и ввод текста, независимость клипов, изменения кадров,
множественная загрузка, замена, сохранение/открытие с медиа, переходы,
окончание воспроизведения, мобильная вёрстка, реальное видео и нативное
перетаскивание пресетов и клипов.

## Текущие границы

Это редактор сцен с предпросмотром. Экспорт результата в MP4/WebM, звуковые
дорожки и ручная расстановка ключевых кадров пока не реализованы. Видео в сцене
воспроизводится без звука и синхронизируется с общей позицией времени.

До 30 клипов в проекте, 30 МБ на загружаемый медиафайл, 100 МБ для библиотеки
(с учётом base64), 150 МБ для открываемого JSON. Поддержка кодеков зависит от
браузера; при неподдерживаемом формате редактор покажет ошибку. Проекты прежнего
редактора (версия 1, без таймлайна) не импортируются.

Pinterest-референсы из задачи не удалось просмотреть: все четыре запроса
отклонены прокси среды с 403. Новые сцены реализованы по описанию задачи,
без заявления о точном повторении референсов.

## GitHub Pages

Публикуйте ветку `main`, директорию `/ (root)`. Все пути относительные:
сайт работает и в подпапке `/for_test/`. После изменения файлов в `main`
GitHub Pages обновит сайт, если публикация уже включена в настройках репозитория.
