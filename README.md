# Forma — motion studio

Редактор анимационных пресетов на HTML, CSS и JavaScript без сборки и зависимостей.

## Запуск

Из `/workspace/for_test` выполните `npm start` (Python 3, порт 3000).
Проверка синтаксиса: `npm run check`.

Шесть пресетов, фильтры, загрузка изображений и видео до 30 МБ, текст,
произвольные размеры композиции, цвет фона, масштаб, скорость, easing,
пауза и перемотка. Файлы обрабатываются локально в браузере.

«Сохранить проект» скачивает JSON настроек. Медиафайл не включается.
Импорт JSON и экспорт анимации в видео пока не реализованы.
Шрифт Inter загружается из Google Fonts; при недоступности используется Arial.
