# Forma 3 — motion lab

Статический редактор анимационных сцен и кинетической типографики.
Работает на GitHub Pages: без сборки, сервера приложения и платных API.
Шрифты, миниатюры и весь код обслуживаются локально с сайта.

## Запуск

```sh
npm start
```

Нужен Python 3, сервер слушает порт 3000. В облачной среде рабочая директория —
`/workspace/for_test`. Используйте существующий checkout; отдельный Git worktree
не нужен. После восстановления машины сервер необходимо запустить повторно.

## Пресеты

В библиотеке 13 настраиваемых сцен:

| Пресет | Движение |
| --- | --- |
| Type rings | Типографические ленты вокруг чёрной сферы |
| Liquid type | Деформируемый красный шар с текстом или медиа |
| Type tunnel | Изогнутое текстовое полотно с узкой серединой |
| Letter ballet | Курсивные слова, вращение букв, смена масштаба и палитры |
| Pattern roll | Повторяющийся и вращающийся типографический паттерн |
| Ribbon helix | Непрерывная спираль из редактируемых лент |
| Type textile | Текст и медиа на волнующемся полотне |
| Объёмный каскад, Орбита, Editorial flow | Согласованные раскладки 3D-карточек |
| Device studio, Волна, Галерея | Устройства, волнообразное движение и сетка |

Новые объёмные сцены используют WebGL: настоящие сетки с UV-текстурами,
нормалями, освещением, глубиной и проверкой попадания мыши по поверхности.
Кинетические сцены рисуются через Canvas 2D; старые карточные — через CSS 3D.
Всё воспроизведение использует одну детерминированную позицию времени.
При отсутствии WebGL новые объёмные сцены покажут объяснение; остальные
пресеты продолжают работать.

Референсы, границы сходства и статус поиска Pinterest/Are.na описаны в
[REFERENCES.md](REFERENCES.md). Шрифты Anton и Instrument Serif распространяются
по OFL; лицензии включены в `assets/fonts`.

## Монтаж и карточки

- Нажмите на пресет или перетащите его на таймлайн. Клипы можно дублировать,
  удалять, переставлять мышью и кнопками, а также менять длину правой границей.
  Автопереходы между клипами используют перекрытие до 0,45 с.
- В пресете до восьми кадров/поверхностей. Загружайте несколько изображений
  или видео, меняйте текст, шрифт и цвет, заменяйте файл, дублируйте кадры.
  Изображения и видео можно нанести на изогнутые поверхности.
- Тяните поверхность мышью прямо в предпросмотре, чтобы поменять X/Y.
  Её можно выбрать и через список справа. В списке кадры переставляются
  перетаскиванием; рядом с каждым есть кнопка быстрого удаления.
- **Delete / Backspace** удаляет выбранный кадр, если выбран кадр, и клип,
  если выбран клип на таймлайне. Контекст показан под таймлайном. В текстовых
  полях эти клавиши работают как обычно.
- **Ctrl/Cmd + Z** или кнопка отмены возвращает последнее действие с кадрами:
  добавление, удаление, перестановку или перемещение мышью. Это история действий
  с кадрами, а не общий undo всех полей редактора. Последний кадр тоже можно
  удалить: останется пустая сцена, в которую можно добавить новый.
- У каждого кадра свои текст, размер шрифта, заливка, размещение медиа, X/Y/Z,
  поворот, масштаб, непрозрачность и задержка появления.
- У каждого клипа свои фон, длительность, скорость, easing, камера, глубина,
  свет и тени. У новых пресетов есть изгиб, вращение, повторы текста, глянец,
  цвет типографики и выбор шрифта. Для Letter ballet можно использовать палитру
  кадров или общий фон, автоматический контраст или заданный цвет текста.
- Размер композиции произвольный, есть форматы 16:9, 1:1, 4:5, 9:16.
  Длительность при скорости 1× делится на скорость для получения длины клипа
  на таймлайне. Звук видео пока не используется.

## Воспроизведение и файлы

Пробел — воспроизведение/пауза; стрелки — ±1/30 с; Shift + стрелки — ±1 с.
Ctrl/Cmd + S сохраняет проект. Горячие клавиши монтажа не перехватывают ввод
в полях, select и contenteditable.

JSON-проекты версии 2 содержат настройки и все используемые медиафайлы.
Старые проекты версии 2 с карточными сценами совместимы с новой версией.
Файлы не отправляются на сервер. Неиспользуемые файлы библиотеки в проект
не включаются. Проекты версии 1 без таймлайна не импортируются.

Текущие границы: до 30 клипов, 8 кадров на клип, 30 МБ на медиафайл,
100 МБ библиотеки с учётом base64, 150 МБ открываемого проекта. Поддержка
видеокодеков зависит от браузера. Экспорт результата в MP4/WebM, звуковые
дорожки и ручные ключевые кадры пока не реализованы.

## Проверки

```sh
npm run check
npm test
```

11 тестов проверяют таймлайн, перекрытия, скорость, детерминированную перемотку,
трансформации, геометрию всех поверхностей, матрицы, easing, переносимость
проектов, пустые сцены и валидацию данных.

Браузерные тесты требуют Playwright, Chromium и работающий сайт.
Задайте `PLAYWRIGHT_MODULE` при нестандартном расположении пакета,
`CHROMIUM_PATH` для системного браузера и `FORMA_TEST_URL` при другом адресе.

```sh
npm run test:browser
```

Проверяются прежний монтаж и видео, все новые пресеты, настоящий GPU picking,
перемещение поверхностей, перестановка и удаление кадров, отмена, пустые сцены,
медиа-текстуры, сохранение/открытие и мобильная вёрстка. Для headless Chromium
используется программный WebGL через `--enable-unsafe-swiftshader`.

## Публикация

GitHub Pages: ветка `main`, директория `/ (root)`. Сайт работает в подпапке
`/for_test/`. Скрипты и стили имеют версию в URL для обхода устаревшего кэша.
Изменения в `main` публикуются автоматически, если Pages уже включён.
